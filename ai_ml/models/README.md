# CAMPUSLINK AI/ML Models

## Current implementation

The current CAMPUSLINK AI/ML implementation primarily uses:

- Rule-based matching
- Eligibility scoring
- Skill-gap analysis
- Question selection
- Adaptive interview logic
- Answer evaluation
- Performance scoring
- Final evaluation
- Computer-vision monitoring

No fake or placeholder `.pkl` model files are included.

## Active AI/ML components

### 1. Student-Job Matcher

Evaluates:

- Student skills
- Programming languages
- Degree
- CGPA
- Experience
- Job requirements
- Skill match
- Eligibility
- Final match score

### 2. Skill Gap Analyzer

Evaluates:

- Required skills
- Existing skills
- Missing skills
- Partial skills
- Skill-gap percentage
- Skill priority
- Learning recommendations

### 3. Assessment Engine

Supports:

- Skill-based questions
- Difficulty-based selection
- Random MCQ selection
- Correct/wrong/skipped evaluation
- Percentage calculation
- Skill-wise performance

### 4. Interview Engine

Supports:

- Job-specific question selection
- Student-specific question selection
- Skill-based questions
- Difficulty levels
- Adaptive question selection
- Open-ended answer evaluation
- Performance scoring
- Feedback generation
- Final evaluation

### 5. Interview Monitoring

Supports:

- Face detection
- Face-not-detected events
- Multiple-face detection
- Looking-away detection
- Excessive movement detection
- Camera status
- Microphone status
- Monitoring events
- Monitoring score
- Monitoring session lifecycle
